# 结构识别：先看懂它是什么，再决定怎么建

> 本文是全套 references 里最重要的一份。
> 建模失败最常见的原因不是 API 用错，是**没看懂原模型的结构**。

## 一、分类流程

拿到一个零件（尤其是别人建的、几十上百个实体的焊接件），
**不要**从第一个实体开始逐个 `box()` 复制。先分类：

```python
for b in md.GetBodies2(0, True):
    bb = b.GetBodyBox()                    # 米
    mp = b.GetMassProperties(1.0)
    bboxvol = (bb[3]-bb[0]) * (bb[4]-bb[1]) * (bb[5]-bb[2])
    vol = mp[3]
    ratio = vol / bboxvol if bboxvol else 0
```

| `ratio` | 判定 | 建法 |
|---|---|---|
| ≈ 1.0（> 0.985） | 实心矩形板 | 一次 `box()` |
| < 0.5 | 空心方管 / 箱型 | 外壳 `box()` + 内腔 `cut_box()` |
| 0.5 ~ 0.985 | 有局部特征的板（倒角/缺口） | 实心 box 起，再补特征 |

## 二、空心件的壁厚反算

不要靠肉眼看，用体积公式解：

```
矩形管：V = (A·B − (A−2t)(B−2t)) · L
```

实测例子：

```
外形 150×150×2830，体积 10,248,109 mm³
(150² − (150−2t)²) × 2830 = 10,248,109
→ (150−2t)² = 18,878.76
→ 150−2t = 137.4
→ t = 6.3            ← 标准方管壁厚
```

## 三、多块薄板 = 一根箱型梁

**这是最容易犯的错。**

原模型里同一个位置出现 4 块 6.3mm 薄板：

```
150 × 6.3 × 2000      ← 上翼板
 6.3 × 237.4 × 2000   ← 腹板
 6.3 × 237.4 × 2000   ← 腹板
150 × 6.3 × 2000      ← 下翼板
```

它们围成一个 **150×250 的封闭截面** → 这是一根 **150×250×6.3 矩形方管**。

**正确做法**：一根方管建完（1 个实体）。
**错误做法**：照抄成 4 块板（4 个实体，看起来像一堆碎片）。

判断依据：4 块板拼起来能围成封闭截面，且壁厚一致 → 就是一个空心构件。

## 四、坐标系不要想当然

SolidWorks 的 Y 轴**不一定朝上**。实测遇到过：

```
台板 8400 × 2400 × 20      → 20 在 Z 向 → Z 是竖直方向
立柱 150 × 2830 × 150      → 2830 在 Y 向 → Y 才是竖直方向
```

**做法**：先读几个已知零件的包围盒，反推"哪个轴是长/宽/高"，再写死坐标。
不要凭名字猜。

## 五、颜色 / 外观要保留

原模型常按构件分色（如桁架橄榄黄、导轨横杆棕色）。
重建时要读出来并跟着构件走：

```python
mat = body.GetMaterialPropertyValues    # 后期绑定下是属性
```

`None` 说明是面级颜色或显示状态，读不到时至少按构件类型给不同颜色，
不要全部建成同色——评审时一眼就看出不对。

## 六、✅ 正确 vs ❌ 错误（本项目真实案例）

需求：把龙门架顶部横柱加长 100mm。

**❌ 第一次做法（错误）**
```
读 95 个实体的包围盒 → 逐个 box() 复制 → 95 个碎片
横柱被拆成 4 块板
颜色全丢
```
几何对了（体积误差 0.0），但**结构不可读**，用户当场指出：
"横杆是矩形方管就直接作为矩形方管建模，不要像胡话一样这里一个那里一个"

**✅ 第二次做法（正确）**
```
先分类：
  立柱 10 根  150×150×6.3 方管     → 10 个空心体
  横柱  5 根  150×250×6.3 方管     → 5 个空心体
  纵梁  2 根  150×150×6.3 方管     → 2 个空心体
  贴片 20 块  250×250×10           → 20 个实心板
  连接片 30 块 10×50×150           → 30 个实心板
共 67 个构件，每个都是一眼能看懂的构件
```
