# 出图自检与交付检查

## 一、audit_drawing

```python
from swforge import audit_drawing
r = audit_drawing(drawing_path)
```

检查项：

| 项 | 说明 |
|---|---|
| 视图越纸幅 | 视图超出图框 |
| 视图重叠 | 两个视图互相压住 |
| 悬空标注 | 标注没挂到真实几何 |
| 引用 / 配置 | 引用的模型是否存在、配置是否正确 |
| 必填属性 | 标题栏必填项是否为空 |
| 版本指纹 | 模型与图纸是否同一版本 |

**已知局限**：文字重叠只做**近似提示**，不是精确判断。
布局建议只覆盖 1-3 个视图。

## 二、delivery_check

```python
from swforge import delivery_check
r = delivery_check(project_dir)
```

交付前总闸，检查文件齐全性、命名规范、图纸与零件对应关系。

## 三、交付前人工过一遍

```
[ ] 所有零件体积/质量与手算一致（误差 < 1 mm³ / 1%）
[ ] 每个零件材质是国标牌号，密度反算通过
[ ] 干涉体积 = 0
[ ] 图纸不缺关键尺寸、标题栏填满
[ ] 属性 CSV ≠ 装配 BOM（这点要在交付说明里写清）
[ ] 检查通过 ≠ 可直接投产（工艺、焊接、热处理仍需人工定）
```

## 四、诚实边界（每次交付都要写）

```
· 形位公差未实现
· 完整孔系标注（位置/深度/孔表）未实现，只有圆边直径标注
· 焊件/切割清单、渐开线齿轮未实现
· 文字重叠是近似提示
· 只在 SolidWorks 2025 SP5.0 上实测
· 属性 CSV 不等于装配 BOM
```

**不要把"离线测试通过"写成"全部实机通过"。**
标了 `sw` 的测试用例需要真实 SolidWorks，不在离线 CI 里跑。
