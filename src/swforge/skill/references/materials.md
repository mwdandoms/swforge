# 材质与密度核对

## 一、国标牌号直接用

**不要**近似成欧美标（如 Q235 → A36、45 → C45）。
被识别成跨标准替代会直接判失败。

可直接用的牌号：

```
碳钢/结构钢   Q235  Q355  45  40Cr  20CrMnTi  65Mn  GCr15  Cr12MoV
铸铁          HT200  QT500-7
不锈钢        06Cr19Ni10  022Cr17Ni12Mo2
铝合金        6061-T6  7075-T6  2A12  ZL104
铜合金        ZCuSn10P1  H62
```

库里没有的自定义材质：

```python
set_custom_material(name="...", density_kg_m3=..., ...)
```

## 二、赋完材质必须反算密度

**这是本项目最有价值的一条检查。**

SolidWorks 新建零件默认密度是 **1000 kg/m³（水）**。
忘了赋材质 → 质量按水的密度算 → **Q235 的质量会错 7.85 倍**，而且不报错。

```python
density = r.mass_kg / (r.volume_mm3 * 1e-9)
```

对照表：

| 牌号 | 密度 kg/m³ |
|---|---|
| Q235 / Q355 / 45 / 40Cr | 7850 |
| 20CrMnTi / 65Mn / GCr15 / Cr12MoV | 7850 |
| HT200 | 7200 |
| QT500-7 | 7100 |
| 06Cr19Ni10 | 7930 |
| 022Cr17Ni12Mo2 | 8000 |
| 6061-T6 | 2700 |
| 7075-T6 | 2810 |
| 2A12 | 2780 |
| ZL104 | 2650 |
| ZCuSn10P1 | 8800 |
| H62 | 8430 |

**判据**：反算值偏离上表 > 1% → 立刻停下查，不要继续建模或出图。

## 三、这个错的真实后果

> 一个 100×60×20 的 Q235 板：
> 正确 3.31 kg，按水算 **0.42 kg**。
> 采购按错的重量下单，现场收货重量对不上，或者干脆少投料。

所以在 README 和对外材料里，这条永远排第一——
**"材质默认密度按水算，质量错 7.85 倍"**。

## 四、材质要保留国标身份

```
✅ Q235
❌ A36 / SS400 / C45 / 1045
```

即使化学成分接近，跨标准替代在工程交付里是不接受的。
