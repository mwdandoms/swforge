日期：2026-11-04。状态：**本地开发、实机验收与归档完成；未推送远端、未发布 PyPI**。

## 问题与改进点

- 新增 `annotations.py`，支持三种粗糙度符号、单个/批量、公差尺寸枚举、对称/双向/极限/配合公差。偏差输入毫米，内部换算米；位置输入米。
- 插入粗糙度时本机忽略坐标，新增 `SetPosition2` 与位置回读。
- 用户发现粗糙度悬空后，新增可见直边枚举与原生附着，支持贴边和引线；回读附着实体，引线端点必须落在目标边。
- 验证视图移动10mm时五个符号同步移动；保存重开仍能读回位置、附着、Ra 与公差偏差。
- 公差唯一匹配，重复数值拒绝猜选；不改变名义值，写入失败尝试恢复原公差。角度/倒角等未验证类型拒绝设置。
- 增加4个 CLI 子命令、5个 MCP 工具，全部沿用 STA worker；公共导出61项，MCP工具27项，CLI子命令23项。
- 自检新增粗糙度附着回读与公差回读；清理限定本轮产物，保留原有文档，跨盘路径不会中断清理。

## 当前优点

符号内容、位置与对象关联均有回读；尺寸公差由调用方明确给定，不猜工程要求。
包含离线故障回归与实机持久化检查。源码为24个模块、9062行（不含测试）。

## 已知限制

- 附着仅验证零件工程图的可见直边；曲边、装配视图附着及其他SW版本未验证。
- 无引线贴边仅开放水平直边，其他方向使用引线。边索引用于当前视图，模型几何变化后应重新枚举。
- 显式图纸坐标和视图轮廓定位仍是独立符号，返回placement=sheet，不可当作指定表面已标注。
- 不自动避让，不自动推荐公差/加工要求，形位公差未实现；图纸仍需人工工艺审核。
- 示例Ra值只用于接口验收，不是生产工艺建议。标题栏的图样名称/代号仍继承模板占位文本，未作为生产图纸交付。
- 失败插入可能留下内存符号，created=True必须检查；公差恢复以rollback_ok回读为准。
- 原有32项pytest实机用例本轮未执行；本轮实机证据来自12项selftest及23项专项验收，不能混称“所有实机测试通过”。

## 下一版优先级、思路与验收标准

1. 曲边与孔/轴附着：通过显式边或面引用定位，验证模型变更、视图缩放后关联保持；PDF箭头落在指定对象。
2. 排版与避让：结合标注外廓做碰撞检查；标准试件PDF无文字交叠、无出界。
3. 形位公差与基准符号：先实测原生API持久化，再开放接口；保存重开可回读完整框格及基准。
4. 版本兼容：在实际不同SW版本上运行相同验收脚本，逐版本记录通过/失败，不推断支持。
