# 粗糙度符号类型实测

日期：2026-11-04。SolidWorks 2025 SP5.0，Interop 33.5.0.53。

本机枚举名称是 `swSFSymType_e`，不是 `swSurfaceFinishSymbol_e`。
通过 `examples` 验证入口及 F 盘 `_tools/probe_v14.py` 的逐项插入、类型与文本回读、PDF 渲染核对。

| 输入 | 回读 | PDF 中的形状 | v1.4 公共接口 |
|---|---|---|---|
| 0 | 0 | 基本长短斜线 | basic |
| 1 | 1 | 长短斜线加横线，去除材料 | machining |
| 2 | 2 | 长短斜线加圆，不去除材料 | no_machining |
| 3 | 3 | 一个倒三角 | 不开放，JIS |
| 4 | 4 | 两个倒三角 | 不开放，JIS |
| 5 | 5 | 三个倒三角 | 不开放，JIS |
| 6 | 6 | 四个倒三角 | 不开放，JIS |
| 7 | 7 | 波浪线 | 不开放，JIS |
| 8 | 0 | 只见 Ra 文本，形状不可靠 | 拒绝 |

0~8 均能读回 Ra=3.2，但 8 类型不一致，说明“对象不为空”不足以证明成功。
初次探测所有位置回读为原点，PDF 上符号堆叠；增加 `SetPosition2` 后坐标与请求一致。
位置必须用米。该记录仅说明 API 行为，不等同于图纸通过任一完整国标合规审查。

原始证据：`F:\SW+AI\04_实测证据\v1.4.0\symbol_probe.json`、同目录 `符号类型探测.pdf` 和 `符号类型总览.png`。
