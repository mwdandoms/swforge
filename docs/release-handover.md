# Community 2.0 本地候选交接

状态：2026-11-19，用户已确认发布 Community 2.0.0，并明确后续继续推进 2018–2026 兼容。此文件记录发布前验收，实际线上发布结果另存发布日志。

## 本轮改进

- 以公开 1.7 提交为基础组装独立社区源码，保留原有 66 项业务操作，新增 6 项；四个 MCP 入口不变。原生特征和普通驱动尺寸进入社区版。
- 工程图、GB、审图、批量交付沿用公开 1.7 功能。对应版本连接、模板、兼容 BOM API 和基础出图可靠性作最小修复；对照及 SHA-256 记录在 COMMUNITY_PROVENANCE.json。
- 螺旋输出转换为无建模历史实体，几何转换前后核对体积和外廓；混合构建也整体转换。参数变化通过新文件重新生成。未把此机制描述为加密或禁止修改开源源码。
- 新版增强工程图、规则包、审图、生产批量、机械连接复核、下料计算实现不进入社区包。按精确文件白名单检查源码、wheel 和 sdist。
- 修复正方形轮廓隐含等长约束导致第二个尺寸成为参考尺寸的问题；显式去除隐含等长关系，保留宽高独立驱动，改值保存重开核对体积。
- 修复 SW2019 隐藏主窗口无法创建基础视图的问题，创建时临时显示并恢复调用前状态。

## 验证与当前优点

离线 397 项通过，33 项历史 SW 标记测试未全量执行。2019 SP5 与 2025 SP5 分别完成 10 项原生特征、6 项螺旋/改尺寸、基础出图及 PDF、3 项净距/干涉、正方形独立改尺寸与 3 项实际 gateway 调用；对应 Interop 各编译通过 17 个引擎。实测能力范围见 validation-community.md / .json，不宣称全部操作均已认证。

社区接口、输出保护和回读机制保持一致；商业模块在打包前即排除。GitHub 与 PyPI 描述采用相同文风并分别适配链接格式，末尾仅一段介绍后续商业方向。第三方来源和 MIT 声明保留。

## 已知限制

螺旋件不保留可调原生历史；不支持变螺距、弹簧闭口磨平或任意导引线扫掠。显式配方关联不是跨文件原生方程。工程图与审图不包含较新私有版本的增强实现；图纸仍需工程审核。两版专项通过不能推断其他年份、补丁、Python 版本或所有参数组合均通过。

安装验证采用独立 wheel 目录，不替换全局安装。测试只清理本轮拥有的文档。完整原始证据由本地验收包提供；早期失败尝试保留在工程证据目录，不隐去失败，也不与最终通过混算。

## 后续维护与商业迭代

社区后续持续推进 SolidWorks 2018–2026 版本兼容，并处理可复现缺陷与安全问题。先提供最小输入，再用保存重开、驱动尺寸改值、体积/外廓和文档归属核对验收，不增加未承诺的新功能。

商业订阅可逐步形成可编辑螺旋工作流、增强工程图、持续 GB 规则、增强审图和批量任务管理；企业定制围绕图框、专用件库、参数化产品及系统对接。独立仓库/构建与权限分发，公共接口契约与私有实现分离；以真实客户样件、明确规则输入、可复核报告和交付一致性作为验收标准。具体范围另行说明，不预售未交付能力。

## 可复现入口

实机入口列于 validation-community.md；源码边界：`python tools/verify_community_release.py`。构建：`python -m build --no-isolation`；描述格式：`python -m twine check --strict dist/<wheel> dist/<sdist>`。所有命令均不执行发布。
