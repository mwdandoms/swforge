# 已知限制

诚实清单。这些是**当前版本做不到**的事，不是"以后会更好"的客套话。

---

## 版本

| 项 | 状态 |
|---|---|
| SolidWorks 2025 SP5.0 | ✅ 完整实测 |
| SolidWorks 2019~2024 | ❌ **未验证** |
| 低版本文件格式 | ❌ 未支持（2025 存的件 2019 打不开） |

生成的 C# 直接调用当前安装的 Interop DLL，所以在 2024 上**大概率能跑**，
但没有实测就不能声称支持。版本兼容是 v0.9 的主要目标。

---

## 几何

| 项 | 说明 |
|---|---|
| 基本形体 | 盒体、平板、4 板拼方管（XYZ）、圆柱（XYZ）、旋转（XYZ）、圆角、倒角 |
| 旋转轮廓 | 必须是闭合多边形，不能自交 |
| 边规则 | 只支持直边（按轴向 + 长度筛选），不支持圆边半径筛选 |
| 负偏移基准面 | 部分版本失效，构建器只在 `y0 > 0` 时插入偏移面 |
| 性能 | 约 **2.65 s/形体**，100 形体约 4.5 分钟 |

---

## 工程图

| 项 | 说明 |
|---|---|
| 自动标注 | `InsertModelAnnotations4` 插模型驱动尺寸，**跨视图去重**，上限约 18 个 |
| 总尺寸 | 已支持，但**右视/俯视的选点可能落在内轮廓上**（实测 114 / 14，应为 100） |
| 尺寸避让 | ❌ 没有自动避让，可能与几何或彼此重叠 |
| **公差** | v1.4 可显式指定对称/双向/极限/配合公差并回读；不自动推荐等级 |
| **粗糙度** | v1.4 支持显式可见直边附着、贴边/引线、批量与独立符号；坐标用米，曲边/装配视图附着未验证，不做自动避让 |
| 形位公差 | ❌ 未支持 |
| 完整标注流水线 | ❌ MechDog 的 `annotations=True` 路径仍出现 PDF `err=1` |

**结论**：v1.4 可按明确要求补尺寸公差与粗糙度，正式生产前仍需人工核对工艺、完整标注和审核签章。详见 [标注用法](annotations.md)。

## 资源与稳定性

| 项 | 说明 |
|---|---|
| 文档上限 | 默认 8 个，超过拒绝创建（可在接口上传参调整） |
| 资源守卫 | 三档（ok / warn / critical）+ 安全清扫 |
| 上限保护范围 | **只保证文档数量**，不保证任意复杂模型不崩溃 |
| 关闭文档 | 只关自己新建的；有未保存修改的一律跳过 |
| 强杀进程 | ❌ 不会，需要用户自行处理 |

## 平台

* Windows only（依赖 COM + Interop DLL）
* Python 3.10+（实测 3.14.3）
* 需要完整的 SolidWorks 安装（不能只装 Viewer）


v1.4.1显式选面的范围与回退限制见 [配合文档](face-mates.md)：仅实测SW2025 SP5.0、顶层已解析零件的圆柱面/平面；子装配、柔性组件和旧版SW未验证。

## 不能挖孔 —— 只能加料

**现状**：`PartBuilder` 提供 `box` / `plate` / `tube_x|y|z` / `cylinder` /
`revolve`，**全部是加料**。没有 `cut`，没有 `hole()`。

**影响**：做不了带孔的真实零件。这一点在 v1.4 之前的演示里曾经被掩盖过——
所谓「Ø16 通孔」实际造出来是凸台，体积从 320000 涨到 324021 mm³
（多出来的 4021 正是 π×8²×20）。装配时销和实心板料打架，
干涉检查报 2 处，那不是 bug，是把销钉进铁里的必然结果。

**试过的路径（全部失败）**：`FeatureCut4`（27 参）、`FeatureCut`（20 参），
配 `T1=0` 给定深度与 `T1=1` 完全贯穿、`D1/D2` 传或不传深度、
`UseFeatScope` true/false、草图放在与实体底面重合的基准面上 —— 
**六种组合一律返回 `null`**，日志无进一步信息。原因未定位。

不做猜测性的「修好」。把失败包装成成功比失败更糟。

**当前可用的替代方案**：`revolve()` 旋转一个闭合环形轮廓，
造出来的是真正的通孔。

```python
# 轴套：内孔 Ø16，外径 Ø50，长 30
b.revolve("轴套", [(8, 0), (25, 0), (25, 30), (8, 30)], axis="y", angle=360)
```

实测体积 52873.0 mm³，理论值 52873.0 mm³，**误差 0.00**。

方孔可以用 `tube_x/y/z()`。

**计划**：需要另找 API 路径，可能是 `IFeatureManager` 的另一组入口，
或者要先用 C# 早期绑定导出草图实体再切除。在此之前不提供 `hole()`——
一个永远抛异常的方法比没有这个方法更让人困惑。
