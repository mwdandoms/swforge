# 2.0 Community 已知限制

- Windows、Python 3.10+；需要合法安装的 SolidWorks。目标版本为 2019 SP5 / 2025 SP5，逐项证据见 validation-community.md。后续将分阶段推进 SolidWorks 2018–2026 兼容，已验证范围将持续更新。
- 工程图、GB、审图、批量交付保持公开 1.7 功能范围；仅增加必要兼容与可靠性修复，没有新版自动选幅、排版或增强审查引擎。
- 弹簧限等螺距、圆线、开放端；输入高度为中心线轴向高度，不是自由高度。绞龙限等螺距。无刚度、疲劳寿命、下料或工艺补偿承诺。
- 含弹簧/绞龙的输出为无建模历史实体，包括同一构建器内的混合实体；不提供原生螺旋/扫掠参数化编辑。可重新生成，可直接编辑实体，不承诺防修改。
- 常用基础轮廓保留驱动尺寸；显式配方关联不是原生方程，也不会自动替换装配引用。
- 变型默认使用新路径；就地改参须显式保存，未保存的用户文档不能接管。
- 基础 GB、GD&T 与装配检查都有覆盖边界，不能代替完整标准审查、强度验证或制造批准。
- 同机并装须选择年份和对应模板/材料库；2025 原生文件不能承诺由 2019 打开。
