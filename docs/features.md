# swforge v1.2.0 功能清单

> 用 Python / 命令行 / MCP 驱动本机 SolidWorks
> 建模、配国标材质、装配配合、查干涉、出 GB 工程图 —— **每一步都回读验证**
>
> 实测环境：SolidWorks 2025 SP5.0 · Windows · Python 3.10+
> 158 项离线测试 + 10 项实机自检 + 双进程并发实测，全过
> `pip install swforge`

---

## 一句话

> **不确定结果对不对的自动化，不算自动化。**

同类工具普遍是「调用没报错就算成功」。swforge 是**每一步都把结果读回来核对**：

- 建完读实体数和体积
- 赋完材质读密度
- 加完配合读位置有没有变
- 出完图读尺寸值对不对
- 查完干涉读精确体积和涉及零件

# 二、材质（同类项目都没有）

| 功能 | 状态 | 说明 |
|---|:---:|---|
| **20 个 GB 国标牌号** | ✅ | 见下表 |
| 自动生成 SW 材质库 | ✅ | `swforge materials` |
| **密度回读验证** | ✅ | 用质量/体积反算 |

**内置牌号**：
```
Q235  Q355  45  40Cr  20CrMnTi  65Mn  GCr15  Cr12MoV
HT200  QT500-7  06Cr19Ni10  022Cr17Ni12Mo2
6061-T6  7075-T6  2A12  ZL104  ZCuSn10P1  H62 ...
```

> ⚠️ **一个真实存在的坑**：SolidWorks 默认密度是 **1000 kg/m³（水的密度）**。
> 不赋材质时它**不报错**，但质量会错 **7.85 倍**。
> swforge 赋完材质会用 mass/volume 反算密度，实测 **7850 kg/m³**。

# 四、干涉检查 ⭐ 最强项

| 功能 | 状态 | 说明 |
|---|:---:|---|
| 单零件多实体干涉 | ✅ | `body_interference` |
| 装配体干涉 | ✅ | `check_interference` |
| **精确干涉体积** | ✅ | 不是「有/没有」 |
| **指出涉及哪两个零件** | ✅ | |

**实测**：两块 20mm 立方沿 X 重叠 10mm
```
理论值  10 × 20 × 20 = 4000 mm³
实测     4000.000 mm³   偏差 0.00%
输出     {'volume_mm3': 4000.0, 'components': ['A-1', 'B-1']}
```

> 修掉了一个隐蔽 bug：`GetInterferences` 在 pywin32 下是**属性不是方法**，
> 调用抛的异常被吞掉，导致「计数 1、明细空」持续存在——调用方知道有干涉，
> 但不知道是哪两个零件。

# 十二、安装与验证

```powershell
pip install "swforge[mcp,pdf]"
```

**前提**：Windows + SolidWorks（手动启动好）+ Python 3.10+

**装完先跑这个**，它会告诉你这台机器上哪些能力真的可用：

```powershell
swforge selftest
```

九项检查全部在真实 SolidWorks 上跑，60 秒出结果。
**失败时会指出是哪一环、对应同类项目的哪个已知问题**，不是笼统的「失败」。

# 一句话总结

> **能做**：建模 → 国标材质 → 装配 → 精确干涉 → GB 工程图 → 批量出图 → BOM 数据，
> 每一步都有回读验证。
>
> **不能做**：公差标注、钣金焊件齿轮、图纸直接投产。
>
> **独一无二**：10 项实机自检 + 精确干涉体积 + GB 材质库。
